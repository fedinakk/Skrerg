# Skrerg Timings — панель таймингов для Premiere Pro (CEP)

Панель показывает тайминги выделенных на таймлайне фрагментов **относительно
исходного клипа (медиафайла)**, из которого они были вырезаны, и позволяет
скопировать эти тайминги в буфер обмена.

Для каждого выделенного клипа отображается:

- **Вход (источник)** — точка входа относительно исходного клипа;
- **Выход (источник)** — точка выхода относительно исходного клипа;
- **Длительность** фрагмента;
- (опционально) **Начало/Конец на таймлайне** — положение фрагмента в секвенции.

Тайминги можно показывать в виде таймкода `HH:MM:SS:FF` и/или в секундах.
Кнопка **«Скопировать тайминги»** копирует данные всех выделенных клипов
текстом в буфер обмена.

## Структура

```
com.skrerg.timings/
├── CSXS/manifest.xml     — манифест расширения CEP
├── index.html            — интерфейс панели
├── css/styles.css        — стили
├── js/CSInterface.js     — мост CEP ⇄ хост-приложение
├── js/main.js            — логика панели
├── jsx/host.jsx          — ExtendScript: сбор таймингов из Premiere
└── .debug                — конфигурация порта отладки (не обязательна)
```

## Установка в Premiere Pro 2026

Панель не подписана, поэтому Premiere по умолчанию её не загрузит. Нужно один
раз включить режим отладки CEP, затем скопировать папку расширения.

### Шаг 1. Включить загрузку неподписанных расширений (PlayerDebugMode)

**Windows**

1. Нажмите `Win + R`, введите `regedit`, Enter.
2. Перейдите в `HKEY_CURRENT_USER\Software\Adobe\CSXS.12`
   (если раздела нет — создайте его; для новых версий Premiere это `CSXS.12`;
   если панель не появится, повторите то же для `CSXS.11`).
3. Создайте строковый параметр (String Value) с именем `PlayerDebugMode`
   и значением `1`.

**macOS**

Откройте Terminal и выполните (при необходимости замените версию CSXS):

```bash
defaults write com.adobe.CSXS.12 PlayerDebugMode 1
killall cfprefsd
```

### Шаг 2. Скопировать папку расширения

Скопируйте папку `com.skrerg.timings` целиком в системную папку расширений CEP:

**Windows**

```
C:\Program Files\Common Files\Adobe\CEP\extensions\com.skrerg.timings
```

или (без прав администратора):

```
C:\Users\<Имя>\AppData\Roaming\Adobe\CEP\extensions\com.skrerg.timings
```

**macOS**

```
/Library/Application Support/Adobe/CEP/extensions/com.skrerg.timings
```

или:

```
~/Library/Application Support/Adobe/CEP/extensions/com.skrerg.timings
```

> Важно: внутри папки `extensions/com.skrerg.timings` должна лежать папка
> `CSXS` с `manifest.xml`, а не ещё одна вложенная папка.

### Шаг 3. Запустить панель

1. Полностью закройте и снова откройте Premiere Pro 2026.
2. Меню **Window → Extensions → Skrerg Timings**
   (**Окно → Расширения → Skrerg Timings**).

## Как пользоваться

1. Откройте секвенцию и выделите один или несколько фрагментов на таймлайне.
2. Нажмите **«Обновить»** (или включите галочку **«Авто»** для автообновления).
3. Галочками сверху выберите формат: таймкод, секунды, позиция на таймлайне.
4. Нажмите **«Скопировать тайминги»**, чтобы поместить данные в буфер обмена.

---

## Примечания

- Таймкод рассчитывается по частоте кадров секвенции. Для дробных частот
  (например, 29.97) используется округлённое число кадров в секунду —
  для точных значений включите отображение в секундах.
- «Вход/Выход (источник)» берутся из `inPoint`/`outPoint` клипа —
  это тайминги относительно исходного медиафайла, из которого взят фрагмент.
- Если панель не появляется в меню — проверьте, что `PlayerDebugMode`
  установлен для правильной версии `CSXS`, и что путь к папке расширения
  указан верно.
